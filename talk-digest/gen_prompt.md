# Skill: 会议访谈内容提炼

## 技能描述

将会议记录、访谈逐字稿、对话内容等原始素材，提炼为三种结构化输出：干货版、一页PPT版、金句版。适用于播客访谈、内部会议、客户对话、专家访谈等场景。

## 触发场景

- 用户提供会议记录/访谈逐字稿，要求提炼核心内容
- 用户需要将长对话转为可传播的短内容
- 用户需要制作会议纪要、分享卡片、PPT素材

## 输入要求

用户需提供以下内容之一：
- 完整的会议/访谈逐字稿
- 会议录音的文字转写结果
- 对话记录的原始笔记

## 输出规范

### 版本一：第三人称干货版

**格式要求：**
- 去掉开场白、客套话、过渡语、口头禅、重复内容、跑题内容
- 保留：独特观点、具体方法、关键数据、矛盾冲突、预测判断、金句
- 按主题分小节，每节3-5个要点
- 每个要点一句话，不加解释性修饰
- 使用第三人称（“他/她认为”、“他表示”）
- 字数控制在800-1500字

**输出顺序：**
1. 一句话总结（20字以内）
2. 正文（分小节，每节配小标题）

### 版本二：一页PPT版

**格式要求：**
- 标题：一句话，12字以内，概括全文核心
- 副标题：一句话，20字以内，补充背景或人物标签
- 正文：表格或分条列出，每行一个观点
- 表格不超过3列，行数不超过10行
- 末尾附一句金句（加粗显示）

**输出顺序：**
1. 标题
2. 副标题
3. 核心观点（表格形式）
4. **金句：**（加粗）

### 版本三：金句版

**格式要求：**
- 提取8-12条金句
- 每条一句话，不超过25字
- 不解释、不连接、不加背景
- 开头可加一句人物/背景标签（如“——张三（某公司CEO）”）

**输出顺序：**
1. 背景标签（可选）
2. 金句列表（每条独立成行，带数字序号）

## 处理步骤

### 第一步：去冗余
去掉以下内容：
- 开场白、客套话、过渡语
- 口头禅、重复、语序混乱的部分
- 与主题无关的闲聊或跑题内容
- 过度解释或铺垫

### 第二步：保核心
识别并保留以下六类内容：
1. **独特观点**——不同于常识的判断
2. **具体方法**——可操作的做法、步骤
3. **关键数据**——金额、人数、时间、比例
4. **矛盾冲突**——与传统做法的对比、失败教训
5. **预测判断**——对未来趋势的结论
6. **金句**——有冲击力、易传播的短句

### 第三步：分类组织
按主题将保留的内容分组，每组提炼3-5个要点。

### 第四步：生成三版本
按上述输出规范，依次生成干货版、PPT版、金句版。

## 使用示例

**用户输入：**
> 请提炼这段访谈逐字稿：[粘贴逐字稿内容]

**AI输出：**
> 一句话总结：AI时代，打工的机会越来越少
>
> 【干货版】...（约1200字）
>
> 【一页PPT版】标题+表格+金句
>
> 【金句版】8-12条金句

## 质量检查清单

输出前确认：
- [ ] 是否去除了所有口语重复和跑题内容？
- [ ] 是否保留了关键数据和独特观点？
- [ ] 干货版是否有明确的小标题和分段？
- [ ] PPT版是否适合直接放入幻灯片？
- [ ] 金句版每条是否在25字以内？
- [ ] 三个版本是否有重复内容过多的问题？

## 常见调整指令

用户可在基础模板上要求：
- “再短一些” → 干货版控制在500字以内
- “只输出金句版” → 跳过其他版本
- “适合小红书” → 增加emoji，每句单独成行
- “加粗关键数字” → 对金额、人数等加粗处理
